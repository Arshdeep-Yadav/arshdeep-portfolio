## ⚡ Portfolio Architecture & Highlights

A dependency-free, high-performance static web application built with vanilla web technologies:

- **Zero Framework Bloat:** 100% Vanilla HTML5, CSS3, and JavaScript — zero npm dependencies required for runtime.
- **Celestial Lighting System:** Interactive Sun & Moon theme toggle that acts as an ambient directional light source casting real-time shadows and rim lighting across UI surfaces.
- **Interactive Career Workbench:** Draggable physics-inspired studio sticky notes with live connection ink lines rendered on HTML5 canvas.
- **Product Dossier Case Studies:** Deep-dive modal architecture detailing architectural tradeoffs, system diagrams, and key decisions for every project.
- **Command Palette:** Quick-access power-user navigation (`⌘ K` or `Ctrl+K`) for keyboard-first navigation.
- **Full SEO & Performance Suite:** Pre-configured JSON-LD structured data, Open Graph card assets, `sitemap.xml`, `robots.txt`, and security headers via `vercel.json` and `netlify.toml`.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/Arshdeep-Yadav/arshdeep-portfolio.git
cd arshdeep-portfolio

# Rust Preview Server (Blazing fast, Gzip + Far-Future Expires headers)
cargo run --manifest-path preview-server/Cargo.toml -- 8000

# Or standard static server
npx serve .
```

Visit `http://localhost:8000` in your browser.
